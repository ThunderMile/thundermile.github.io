# Mile Huang’s portfolio

A buildless English portfolio for [thundermile.github.io](https://thundermile.github.io/). The homepage is `index.html`. The project page is `projects/widefield-assembly/index.html`. All site assets are served locally.

## Preview and publish

From the repository root, run `python -m http.server 8000` and visit `http://localhost:8000/`. For GitHub Pages, push the files to `main` and select **Settings → Pages → Deploy from a branch → main → / (root)**.

## Update the project

- Edit the project page’s **Project context** and **My contributions** sections to add confirmed decisions, collaborators, or outcomes.
- To add a screenshot, put its image in `assets/media/` and duplicate a gallery figure. Update the link, image path, dimensions, alternative text, and caption together.
- To replace the demo, update the MP4, poster, duration, and accessible description in the **Unreal demo** section. If the replacement includes speech, add a caption track.

## Content and media sources

Mile supplied the academic profile, interests, engine version, and original demo. The site’s video is a 720p copy of `OSPOPresentationDemo.mp4` with its silent audio track removed. Gallery images are frames from that recording. The homepage component study isolates the optical mounts at 00:27.28 and provides an outline derived from the same frame.

The project’s three modes are documented in the [WideField Assembly repository](https://github.com/uw-loci/WideFieldAssembly). The internship dates and program are listed in the [UW–Madison project catalog](https://ospo.wisc.edu/project-catalog/opentirf/).
